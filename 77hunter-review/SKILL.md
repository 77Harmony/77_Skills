# 功能说明
基于用户提供的SKU或品类，分析京东用户评价中的高频需求词和差评词，输出可用于产品策略和广告素材优化的洞察。

# 输入要求
- 用户需提供SKU编号或品类名称
- 如无SKU，基于品类通用评价趋势分析
