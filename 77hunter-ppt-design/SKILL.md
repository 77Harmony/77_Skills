# 功能说明
交叉对比本品卖点与竞品弱点，输出差异化优势矩阵，直接用于竞品分析页和产品策略页。

# 输入要求
- 本品SKU或产品名称
- 竞品品牌名称（1-3个）

- 过渡页遮罩：不使用纯黑，改用深红黑渐变（上深下略浅）

# 平台视觉适配
- 京东方案（默认）：白底+暗红#C00000+黑+暖灰，封面/过渡页遮罩深红黑渐变
- 小红书方案（触发加载）：白底+小红书红#FF2E4C+黑+暖灰，过渡页遮罩改用小红书红黑渐变
- 抖音方案（触发加载）：白底+抖音青#00FAF0+黑+暖灰，或黑白撞色风格，过渡页遮罩改用抖音青黑渐变
- 其他设计规则（圆角矩形、阴影、字体、图标）三平台通用不变

# 页面排版规范
## 标准三段式结构（除豁免版式外默认采用）
- 顶部：标题 + 总结句（20-80字），总结句上方或下方统一加1-2px暗红细横线作为视觉落点
- 中部：左右分栏展示核心内容（左侧图表/表格/文字，右侧补充说明/数据/图示）
- 底部：收尾区，可使用圆角矩形卡片、长矩形总结框、icon+文字等形式

## 标题规范
- 格式：章节名丨内容标题
- 示例：市场洞察丨吹风机市场持续高端化，高速品类三年增速超40%

## 版式节奏控制规则
- 同一章节内，连续两页不得使用完全相同的版式结构
- 如果在同一基础版式上叠加了不同元素（第二页加了表格、第三页加了卡片），则不视为重复
- 版式B（中心观点四周数据）和版式F（卡片阵列式）可作为节奏调剂
- 过渡页（版式H）不计入连续页数统计

## 图表解读规范（强制执行）
每个数据图表下方必须包含：
- 建议图表类型：如分组柱状图、饼图、折线图、气泡图等
- 图表核心重点：10-30字为宜，若含义复杂可放宽至40字，以通顺完整为前提
- 详细解释：阐述数据背后的逻辑推导、策略指向、对品牌的具体指导意义

## 图表信息分层规则（强制执行）
- 图表本身只展示数据对比（数值、占比、趋势），不包含策略描述
- 策略描述（出价逻辑、人群标签、核心任务）放在图表下方的“详细解释”区域
- 若表格同时包含数据和策略且信息密度过高，自动拆分为两页：第一页数据表，第二页策略卡片
- 图表中的文字仅限于数据标签、轴标签、图例，不出现完整句子

## Z型阅读路径豁免
- 版式B（中心观点四周数据）、版式H（全图出血）、中心辐射式、环形闭环式不受标准三段式限制

# 宣讲聚焦规则
1. 每页一个视觉锚点：核心数字或结论放大为正文3-4倍，独立占位，周围留白
2. 暗红引导线：复杂推导页用1-2px暗红虚线串联关键节点

# 可读性规则
3. 四色体系：白底+暗红+黑+暖灰卡片底。调用模板库任何版式时，原模板配色必须替换为此四色体系，禁止引入新颜色。除非用户明确说“这次配色可以用XXX色”
4. 信息四层分层：大标题→总结句→支撑点→底部标签，用间距和字重严格区分
5. 表格减噪：去掉内部竖线，只保留表头下沿和底部横线，行与行暖灰/白交替底色，核心数据暗红加粗放大
6. 页面密度控制：一页一个核心信息，超3个独立论点或2组图表即拆页

# 设计细节规则
7. 全局统一圆角半径：所有圆角矩形固定8-10px
8. 图标统一线性风格：全选线性图标，暗红色，统一尺寸，等距对齐
9. 留白呼吸感：文字距卡片边缘至少1cm，卡片距页面边缘至少1.5cm，块间距大于行间距

# 核心页面规则
- 每页必须有标题 + 一句总结（20-80字），总结句上方或下方统一加1-2px暗红细线
- AI生成每页前，先输出：“本页核心信息：XXX”
- 如内容过多，自动拆为两页，第二页用版式F承接

# 8大核心版式
- 版式A：上下结论式（洞察分析、总结），标准三段式
- 版式B：中心观点四周数据（人群洞察、模型总览），豁免标准三段式
- 版式C：左右分栏对照式（创意素材对比、人群对比），标准三段式
- 版式D：全表格矩阵式（预算、SOP、人群包），标准三段式
- 版式E：流程图/时间轴式（策略推导、全年节奏），标准三段式
- 版式F：卡片阵列式（多模块并列），标准三段式
- 版式G：Z型阅读引导式（复杂逻辑叙事），标准三段式
- 版式H：全图出血+半透明遮罩式（过渡页、封面），豁免标准三段式

# 扩展布局库
当原生版式无法完美承载当前页信息时，按模板库选用。所有模板版式调用时，原模板配色必须替换为四色体系。

# 图表与数据可视化
- 图表背景：白色，无边框
- 柱状图：重点数据暗红，其余黑色或灰色；强调数据柱上方加暗红虚线框
- 折线图：重点折线暗红，其余黑色细线
- 组合图：暗红折线+黑色/灰色柱状
- 数字标注：核心百分比放大加粗暗红，必要时暗红虚线圆圈/方框圈出

# 页面留白
- 左右留白：1.5-2厘米
- 上下留白：0.5-1厘米，内容较少时垂直居中可增至2-4厘米
- 核心内容距边缘不少于1.5cm

# 图片与素材
- 人群分析：真实生活场景人物，统一加淡暗红滤镜
- 产品图：透明底PNG
- 图标：WPS自带线性图标库，统一暗红色
- 封面/过渡页：抽象科技或数据背景图，遮罩用深红黑渐变

# 广告素材规则
- 所有广告图统一横版左文右图排版，尺寸1080×720
- 不支持图像输出的模型：输出排版描述+AI提示句（仅中文）
- 支持图像输出的模型：直接生成图片
- 品牌/品类/目标自动替换提示词中的产品、场景、卖点
- 以上卖点基于SKU[编号]京东详情页提取，若与最新版本不符，请提供最新SKU后重新生成

# 广告合规提醒
- 避免使用“第一”、“最好”、“唯一”、“顶级”等极限词
- 功效类描述需与产品详情页资质一致
- 价格类描述需与促销活动实际价格一致
- 对比类文案不得贬低其他品牌
- 如不确定某条文案是否合规，标注“[建议法务/平台审核确认]”

# 全局自检清单（生成完整方案后自动执行）
- [ ] 各页数据是否前后矛盾
- [ ] 人群占比总和是否等于100%
- [ ] 预算占比总和是否等于100%
- [ ] 竞品名称是否前后一致
- [ ] 策略建议是否在后续页面有对应落地动作
- [ ] 所有暗红色是否统一为#C00000（或对应平台强调色）
- [ ] 所有字体是否为微软雅黑
- [ ] 是否有页面标题+总结句+暗红细线
- [ ] 每个图表是否有建议图表类型+核心重点+详细解释
- [ ] 图表是否只放数据，策略是否放在详细解释中
- [ ] 所有数据是否有来源标注或“模拟/拟定”标注
- [ ] 每页是否有且只有一个核心信息
- [ ] 是否存在非京东生态术语
- [ ] 图表颜色规则是否一致
- [ ] 是否有任何动画残留
- [ ] 页面核心内容是否距边缘1.5cm以上
- [ ] 案例数据是否已脱敏标注
- [ ] 产品卖点基于真实SKU提取（若未提供SKU标记为待确认）
- [ ] 所有自行补充内容已标注
- [ ] 是否连续两页使用完全相同的版式
