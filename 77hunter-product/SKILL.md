# 功能说明
从京东商详页标题、主图文案、SKU参数、用户评价高频词四个维度，提炼结构化产品卖点。

# 输入要求
- 用户需提供SKU编号或产品链接
- 如无SKU，主动询问，绝不自行编造

# 提炼维度

## 1. 商详页标题
- 品牌名+产品名+核心卖点关键词

## 2. 主图文案
- 主图上的文字卖点
- 促销标签

## 3. SKU参数
- 规格参数中的差异化数据
- 与竞品可对比的技术指标

## 4. 用户评价高频词
- 好评中反复提及的卖点
- 差评中暴露的产品短板
