# 功能说明
在方案完成后，逐页检查视觉规范和逻辑一致性，输出不符合规则的页码、违规项、修改建议。

# 检查维度

## 一、视觉规范检查

| 检查项 | 规则 | 违规时输出 |
|---|---|---|
| 暗红色统一 | 全部使用 #C00000（或对应平台强调色） | 页码+具体位置+色值偏差 |
| 字体统一 | 全部使用微软雅黑 | 页码+具体文字+当前字体 |
| 圆角矩形阴影 | 所有圆角矩形加WPS默认右下阴影 | 页码+缺失阴影的形状 |
| 图标风格统一 | 全部使用线性/轮廓图标 | 页码+混用的面性图标 |
| 表格减噪 | 无内部竖线，仅表头下沿和底部横线 | 页码+违规表格 |
| 留白规范 | 核心内容距边缘1.5cm | 页码+贴近边缘的元素 |

## 二、逻辑一致性检查

| 检查项 | 规则 | 违规时输出 |
|---|---|---|
| 数据前后矛盾 | 各页引用同一数据时数值一致 | 页码+矛盾数据对比 |
| 人群占比总和 | 等于100% | 页码+实际总和 |
| 预算占比总和 | 等于100% | 页码+实际总和 |
| 竞品名称一致 | 全方案竞品名称统一 | 页码+不一致的名称 |
| 策略有落地 | 洞察结论在后续页面有对应策略 | 未落地的洞察结论 |

## 三、内容合规检查

| 检查项 | 规则 | 违规时输出 |
|---|---|---|
| 极限词检测 | 无“第一”、“最好”、“唯一”等 | 页码+具体词汇+建议替换 |
| 跨生态术语 | 无非京东术语（京东方案） | 页码+违规术语 |
| 数据来源标注 | 所有数据有来源或“模拟”标注 | 页码+缺失来源的数据 |

# 输出格式

## 检查结果总览
- 检查页数：XX页
- 违规总数：XX处
- 严重违规（影响交付）：XX处
- 轻微违规（建议优化）：XX处
