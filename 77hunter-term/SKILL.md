# 功能说明
将京东生态术语自动替换为小红书、抖音或通用营销术语，确保跨平台方案的专业度。

# 术语对照表

## 京东 → 小红书

| 京东术语 | 小红书对应术语 |
|---|---|
| 搜索广告 | 搜索推广/信息流推广 |
| 推荐广告 | 浏览推荐/相关推荐 |
| 品牌展位 | 品牌专区 |
| 京东直投 | 站外投放/跨平台引流 |
| 京准通 | 小红书广告投放平台 |
| DMP/数坊 | 人群资产/数据洞察 |
| 4A模型 | AIPL模型（阿里系，慎用，优先用“人群资产模型”替代） |

## 京东 → 抖音

| 京东术语 | 抖音对应术语 |
|---|---|
| 搜索广告 | 搜索竞价/搜索广告 |
| 推荐广告 | 信息流广告/原生广告 |
| 品牌展位 | 品牌专区/TopView |
| 京东直投 | 千川投流/站外引流 |
| 京准通 | 巨量千川 |
| 购物触点 | 直播间广告/商品卡 |

## 京东 → 通用营销术语

| 京东术语 | 通用术语 |
|---|---|
| 搜索广告 | 搜索竞价广告 |
| 推荐广告 | 信息流广告 |
| 品牌展位 | 品牌曝光广告 |
| 京东直投 | 程序化投放/站外引流 |
| DMP | 数据管理平台/人群包 |
| ROI | 投资回报率 |
