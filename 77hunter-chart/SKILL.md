# 功能说明
根据数据类型和分析目的，推荐最合适的图表类型，并输出该图表在WPS中的完整制作参数。

# 输入要求
- 数据类型（对比/趋势/占比/分布/关系）
- 数据表内容

| 参数项 | 设置值 |
|---|---|
| 图表类型 | 分组柱状图/折线图/饼图/气泡图... |
| 数据系列颜色 | 重点数据：暗红#C00000；其他：黑色/灰色 |
| 数据标签位置 | 柱顶/柱内/线上/外侧 |
| 轴线样式 | 实线/虚线，颜色，粗细 |
| 图例位置 | 底部/右侧/顶部 |
| 网格线 | 仅横向/仅纵向/无 |
