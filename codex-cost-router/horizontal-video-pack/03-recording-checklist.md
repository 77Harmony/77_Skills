# 录屏清单

## 基础设置
- 画幅：1920x1080，16:9。
- 帧率：30fps 即可。
- 鼠标：开启高亮或后期加放大圈。
- 录屏节奏：鼠标移动慢，停留 1-2 秒给观众读字。

## GPT 对话框录屏
1. 录一段“模糊大任务”示例：输入“帮我优化整个项目，让它更快更稳定”。建议 8-10 秒。
2. 录一段“对话历史很长”的界面：滚动 2-3 屏，表现上下文成本。建议 6-8 秒。
3. 特写输入框和大段需求，后期标注“大范围、目标不清、成本高”。建议 5 秒。

## Codex 实操录屏
1. 展示在 Codex 中说明“先使用 codex-cost-router 做预检，不执行修改”。建议 8 秒。
2. 展示 Skill 输出结构：Task Summary、Complexity、Cost Risk、Model、Reasoning、Prompt。建议 15 秒。
3. 局部特写 Final Optimized Codex Prompt。建议 8 秒。
4. 展示“先路由，再复制执行 Prompt”的动作。建议 6 秒。

## Skill 文件夹录屏
1. 打开当前目录，展示 `SKILL.md`、`README.md`、`references/`。建议 6 秒。
2. 打开 `SKILL.md`，展示 Purpose、Core Principle、Key Output。建议 10 秒。
3. 打开 `README.md`，展示使用方式和输出字段。建议 8 秒。
4. 展示 `references/` 文件结构，不展开大文件。建议 5 秒。

## 鼠标放大与特写
- 放大 `Do not execute first`。
- 放大 `Recommended Model / Model Tier`。
- 放大 `Final Optimized Codex Prompt`。
- 放大目录中的 `references/`。
- GPT 输入框和 Codex 输出区各做一次局部特写。
