# 剪映时间轴

| 时间 | 素材 | 字幕 | 标注 | 音效/转场 |
|---|---|---|---|---|
| 0-5s | `intro-title.html` 录屏 | 额度不是烧在写代码，而是烧在盲目执行。 | 标题居中 | 淡入 + 低频脉冲 |
| 5-15s | GPT 对话框录屏 | 大任务 + 模糊目标 = 高上下文成本。 | 红框标注“大范围需求” | 推近 + 轻点击 |
| 15-30s | `token-waste-flow.html` 录屏 | 全项目扫描、高推理、反复执行，成本会叠加。 | 节点逐个高亮 | 电子扫过 |
| 30-42s | Skill 文件夹录屏 | 这是一个执行前成本路由 Skill。 | 标注 `SKILL.md`、`README.md`、`references/` | 硬切 |
| 42-55s | `SKILL.md` 和 `README.md` 录屏 | 它不是执行器，而是执行前的路由器。 | 放大 Purpose / Core Principle | 轻 whoosh |
| 55-70s | Codex 调用 Skill 录屏 | 先判断复杂度、风险、上下文和权限。 | 框选预检报告字段 | 键盘声 |
| 70-80s | Codex 输出 Prompt 录屏 | 最后生成更省 token 的执行 Prompt。 | 框选 Final Prompt | 成功提示 |
| 80-92s | `model-decision-card.html` 录屏 | 轻任务用轻模型，高风险任务再上高推理。 | 三层模型卡片 | 卡片音 |
| 92-100s | `cost-router-flow.html` 录屏 | 模型选择要和任务成本匹配。 | 流程线流动 | 电子流 |
| 100-112s | `before-after.html` 录屏 | 直接执行是摸路，先路由是先框路径。 | 左右对比 | 对比切 |
| 112-120s | `ending-card.html` 录屏 | 先路由，再执行。 | 金句居中 | 淡出 |

## 剪辑参数
- 项目比例：16:9。
- 字幕：白色，48-58px，底部安全区，描边 4px。
- 标注：蓝紫描边，不用大红大黄。
- 背景音乐：低音电子氛围，音量 -25dB 到 -18dB。
- 旁白：音量约 -6dB，压过背景音乐。
