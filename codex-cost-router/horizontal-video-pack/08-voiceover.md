# 完整旁白稿

很多新手第一次用 Codex，额度不是花在写代码上，而是花在还没想清楚就开始执行上。

比如一句“帮我优化整个项目”，听起来很正常，但对 Codex 来说，这可能意味着先读目录、扫描大量文件、推理整体架构，然后再反复尝试命令。

真正贵的不是某一次回复，而是全项目扫描、高推理、反复执行、权限过宽这些动作叠在一起。

codex-cost-router 是一个 Codex 执行前成本路由 Skill。

它不直接写代码，也不替你改项目。它的作用是在 Codex 真正开始读项目、改文件、运行命令之前，先做一次预检。

这次预检会判断任务复杂度、成本风险、上下文范围、推荐模型、推理档位、速度模式、权限范围，以及是否需要分阶段执行。

在 Codex 里调用它，你会先得到一份结构化报告：哪些文件需要读，是否应该先只读分析，是否需要高推理，哪些命令权限应该先收窄。

最后，它会生成一段更省 token、更安全、更可控的 Codex 执行 Prompt。

轻任务用轻模型，中等任务用标准模型，高风险重构再上更强模型和更高推理。

模型选择不是炫配置，也不是越强越好，而是让任务成本、上下文范围和执行风险匹配。

直接执行，是让 Codex 自己摸路。先路由，是把路径、权限和预算先框出来，再让 Codex 开工。

对新手来说，这一步往往比多买额度更重要。

记住一句话：先路由，再执行。
